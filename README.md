# My Projects – Embedded Systems & Linux Programming

Welcome to my project repository! This repository contains my hands-on implementations and learning projects in **C Programming, Embedded Systems, Microcontrollers, and Linux System Programming**.

The objective of this repository is to strengthen my problem-solving skills, understand low-level system operations, and develop practical software solutions using C and Embedded C.

## Projects

### 1. Address Book

**Domain:** C Programming

A console-based contact management application developed using C.

**Key Concepts:**
- Structures and pointers
- File handling and persistent storage
- Searching and managing contact records
- Modular programming
- Dynamic data management

**Core Operations:**
- Add new contacts
- Search contacts
- Edit existing contact details
- Delete contacts
- List saved contacts

**Technologies:** C Programming, GCC, Linux

### 2. Car Black Box

**Domain:** Embedded Systems

An embedded automotive event-monitoring system developed using the PIC16F877A microcontroller.

The system records and displays vehicle-related events using peripheral interfacing and non-volatile memory.

**Hardware Components:**
- PIC16F877A Microcontroller
- DS1307 Real-Time Clock
- 24C02 EEPROM
- Character LCD
- Matrix Keypad
- UART Communication

**Key Concepts:**
- Embedded C programming
- Microcontroller peripheral interfacing
- I2C communication
- RTC interfacing
- EEPROM data storage
- LCD and keypad interfacing
- UART communication

**Key Features:**
- Event logging
- Timestamp-based event recording
- Event viewing through LCD
- Persistent storage using EEPROM
- Keypad-based navigation

### 3. MiniShell

**Domain:** Linux System Programming

A custom command-line shell developed using C to understand Linux operating system internals and process management.

**Key Concepts:**
- Process creation and management
- `fork()`, `exec()` and `wait()`
- Signal handling
- Inter-Process Communication
- Pipes
- Job control
- Foreground and background execution

**Key Features:**
- Custom command prompt
- Command execution
- Signal handling using Ctrl+C and Ctrl+Z
- Foreground and background process management
- Job listing and control
- Pipe-based command execution

**Technologies:** C Programming, Linux, GCC, POSIX System Calls
